## NM I AI 2026

This repository is for NM I AI 2026 (norwegian AI championship).

## Rules

- Analyze and understand the rules of the **Astar Island** game. Use information available in GAME_RULES.md as well as the NMIAI mcp server.
- **NEVER run the live game (`python3 run.py`) unless explicitly asked.** Always test changes via offline backtests (`offline/run_local.py --backtest-full`). Live runs consume real API budget and submit real predictions.
