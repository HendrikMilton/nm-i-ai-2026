# Support – Tripletex – For Developers
# URL: https://developer.tripletex.no/docs/documentation/support

Support

Avoid directing your end user to Tripletex customer support regarding an issue with your integration. The end user and the customer has little to no access to logs, and Tripletex support will most likely not be able to assist if the issue lies with the request or your integration. Having them request support on your behalf will most likely cause delays in resolving the issue.

As an integration developer you should gather request ID, request body and response body if relevant and forward the request to us via the developer support pages here.
