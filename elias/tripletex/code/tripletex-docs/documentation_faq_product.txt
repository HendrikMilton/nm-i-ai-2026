What is discountGroup used for?

This endpoint is currently only in use internally in Tripletex as part of our wholesale integration and of no use to external developers.

When I specify an inventoryLocationId to a productLine in stocktaking endpoints the API returns null, why?

This field (location) is readOnly and for internal use only as of now, this is not shown in Swagger due to location being a subDTO. Changing inventory location is only supported via the Tripletex webapp. If your end user needs to change the location of product lines in a stocktaking for instance this needs to be done via GUI before the stocktaking is finalized/closed.

This applies to all stocktaking endpoints in general.
