When is department required for creating employees?

If department functionality has been activated at any point, then all new employees must be assigned a department. This persists even if the functionality is deactivated afterwards.

How to check if department functionality has been activated

The field departmentManager is excluded from the GET /department response, and only the default department called “Avdeling” is returned, if department functionality has not previously been activated in the target account. This can be enabled by checkmarking “Department costing”, under Accounts > Settings > Accounting rules > Modules, in GUI.
